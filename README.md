*MSc Thesis, UCL · Supervised by Simon Julier & Sajad Saeedi*

## 陶邑潇

我主要关注**空间智能（Spatial Intelligence）**，尤其是大模型与几何视觉方法交汇处的机器人技术。

大模型非常擅长理解一个物体**是什么**，却未必擅长准确判断它**在哪里**。我的研究与工程实践主要围绕这一差距展开。

**目前：** 在杭州从事空间智能与 4D 世界模型相关研发 · 伦敦大学学院（UCL）机器人与人工智能硕士（2026）

### 代表项目

**SAV-SLAM — 基于证据分级的视听声源归属系统**

UCL 硕士毕业论文 · 导师：Sajad Saeedi、Simon Julier

结合声学定位、视觉 SLAM 与三维几何关联，在无需任务特定训练的条件下，将声源关联到三维地图中的可见物体；当证据不足时，系统明确保留歧义，而不是给出缺乏依据的确定性判断。

**loop-lens — 面向回环检测的视觉地点识别**

探索视觉地点识别在 SLAM 回环检测中的应用。

**港区工业视觉检测（实习项目）**

面向复杂港口监控场景，在真实部署约束下开展目标检测。
